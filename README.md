# medical-disclaimer-rail · 医疗说明条

给已粗剪 / 已加章节导航的竖屏口播视频，在画面底部居中叠一条半透明医疗免责说明小字。

风格对齐抖音账号「青姐聊多囊备孕」成片里的说明条：无底框、半透明白字、贴底、全程叠加。

## 用法（Grok Bot）

装好技能后可以说：

- 「给这个视频加医疗说明条」+ 视频路径
- 或 `/医疗说明条` 再附路径

默认文案：

```
本视频为健康科普与个人经验分享，不构成医疗诊断，
备孕问题请咨询专业医生。
```
